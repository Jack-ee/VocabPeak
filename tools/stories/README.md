# AI 短文：编写与发布

VocabPeak 的「AI 短文」是按《英语·单词本》3500 词的字母顺序编写的阅读材料。现有 S0001–S0107 共 107 篇、2306 个目标词，词窗清单在 `windows/W01–W11.txt`（每窗 220 词对应 10 篇），S0106–S0107 是补充篇。它与教材课文分开存放和统计，阅读、点词、填空、短语四步与课文共用。本目录是它的源稿和发布工具。

## 流程

1. 在 `src/` 写一篇 `Sxxxx.py`（复制现有文件改），一篇一个 `STORY` 字典。
2. 运行 `python tools/stories/build_stories.py --report`，只做校验，不写文件。
3. 校验通过后去掉 `--report` 再运行，发布到仓库根目录的 `stories/`。内容没变的篇目保留原 `_v`，应用不会重复下载。
4. 提交 `stories/` 和 `src/`。应用启动后会增量拉取新篇目，`Build audio pack` 工作流也会被触发，给新句子合成朗读。

## 源稿格式

- `id`、`title`、`titleZh`、`genre`：genre 用英文小写，可选值有 narrative、popular science、news feature、argumentative、letter、speech、interview、diary、biography、travel、dialogue、report、review、blog、fable。
- `paras`：段落列表。每段是若干 `(英文句子, 中文译文, 是否长难句)`。
- `words`：目标词列表。每项是 `(原型, 文中词形, 词性, 语境释义, 句序号, 搭配英, 搭配中)`。句序号从 1 开始，全文连续编号。
- `gloss`：可选。超纲词如果统一词库和离线词典都查不到，必须在这里给中文，点词时显示。
- `narrator`：可选。用来指定朗读者音色，缺省时按篇号在 coral、fable、nova、ash、echo 里轮换。

## 校验规则（build_stories.py）

| 项目 | 要求 |
| --- | --- |
| 目标词 | 至少 20 个，原型在统一词库里，不是 B 级，同系列不重复 |
| 定位 | 每个目标词的文中词形能在指定句子里按词边界找到 |
| 篇幅 | 250 到 420 词 |
| 超纲 | 非目标词还原原型后不在词库的比例不超过 4% |
| 注释 | 词库和词典都没有的超纲词必须写 gloss |
| 译文 | 每句都有中文 |

## 写作要求

这些要求来自家长（"连贯、符合高中水平，不能太简单或者太复杂"）和样稿审读，校验脚本查不出来，要靠人审：

- 目标词按默写本顺序取一个窗口，每篇 22 个左右。一篇围绕一个具体情境写成连贯的故事或文章，不为凑词硬塞。一句里最多放两到三个目标词，近义词不要扎堆在同一段。
- 难度对准高一：以 B1–B2 为主，句长以 12 到 25 词为主，每篇 4 到 7 个长难句（标 True）。非目标词尽量在词库里。
- 搭配要真实常用，宁可选课本和词典里的高频搭配，也不要自造。搭配的中文要和英文严格对应。
- 科普内容必须事实准确。数字和机制宁可写得保守，也不要编造研究结论。涉及烟酒药的内容只用"医生提醒成年人"的口吻。每篇开头用 `# 事实` 注释列出依据的真实事实，供编辑核对。
- 场景贴近中国高中生的生活。中国乡镇写"镇长"不写"镇议会"，用英亩时在译文里附市亩换算。
- 拼写用牛津式英式拼写（programme、travelled、realize），和词库一致。
- 译文用自然的中文，避免"经历了……的下降"这类翻译腔。
- 体裁轮换，相邻几篇不要重复同一体裁。

## 审读流程

每批 10 篇由一位作者按词窗编写，再由另一位编辑独立审读后才发布：核对 `# 事实` 里列出的每条事实（能查到出处的才保留，查不到的改成保守说法），检查搭配是否真实常用且与文中词义一致、指代与时间顺序、中国场景是否写实、外国场景的本地细节，以及中文译文。编辑把审读结论写在 `# 审读` 注释里。

题材敏感的考纲词（abortion, arrest, bomb, communism, communist, divorce, drunk, gay, left-wing, missile, murder, prison, prisoner, pub, savage, sex, slavery, theft, tobacco, unrest）没有在常规篇里硬塞，而是集中写成两篇补充篇：S0106「历史周」报道（法国大革命、废奴、中国共产党成立、两弹一星、曼德拉与罗本岛），S0107 交换生来信（未成年人烟酒保护、酒驾法规、自行车被盗、性别歧视法、侦探小说、华兹华斯诗中 gay 的旧义）。写法与教材一致：事实准确、语气平实、不渲染。补充篇用 `STORY['minTargets']` 把目标词下限放宽到 10（最低 10）。

## 相关文件

- `tools/lexicon/build_lexicon.py` 生成统一词库 `lexicon-3500.js`，构建脚本和应用的点词查词都用它。
- `stories.js` 是应用端的订阅模块，负责存储和 HSVLex 查词。
- `tools/generate_audio_pack.py` 直接读 `stories/` 合成朗读：整篇一个朗读者；目标词原型按单词表的规则合成全部音色，文中词形与搭配只用朗读者音色。
